River Intro (Beginner)

Perfect for first-timers and families. Learn paddling basics, enjoy scenic views, and build confidence with gentle rapids.

  • Duration: 3 hours
  • Difficulty: Class I–II
  • Minimum age: 8+

Canyon Run (Intermediate)

A balanced trip with exciting rapids and time to enjoy the canyon. Great for adventurous beginners and intermediate rafters.

  • Duration: Half-day
  • Difficulty: Class II–III
  • Minimum age: 12+

High Rapids Challenge (Advanced)

Big water, powerful waves, and fast decision-making. Built for experienced rafters who want an intense ride with expert guiding.

  • Duration: Full-day
  • Difficulty: Class III–IV
  • Minimum age: 16+
